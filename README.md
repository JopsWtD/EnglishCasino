# Ruleta de Clase

Sorteo de estudiantes (ruleta o poker) y cinco juegos de casino para la clase de inglés: ruleta europea, tragamonedas, reacción, mayor o menor y blackjack.

## Verlo en tu computador
Abre `index.html` con doble clic (Chrome, Edge o Firefox). No necesita instalar nada.

## Publicarlo en GitHub Pages
1. Crea un repositorio y sube esta carpeta tal cual (`index.html`, `css/`, `js/`).
2. En el repositorio: **Settings → Pages → Build and deployment → Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. En uno o dos minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Notas
- La lista de estudiantes se guarda en el navegador (localStorage) de cada computador.
- Las fuentes se cargan desde Google Fonts; sin internet se usa una fuente del sistema.
